### API Access

Access the Quantum Bridge API directly from your VSCode extensions:

```javascript
// Get the Quantum Bridge API
const quantum = vscode.extensions.getExtension('quantum-bridge.vscode-quantum-integration').exports;

// Connect to other IDE
await quantum.bridge.connect({
  target: "claude_code",
  path: "/mnt/d/projects",
  frequency: 720.0,
  coherence: 1.0
});

// Perform Grover search
const results = await quantum.groverSearch.search("quantum bridge implementation", {
  dimensions: [3, 5, 7],
  coherenceThreshold: 0.93
});

// Open file from search results
if (results.length > 0) {
  const document = await vscode.workspace.openTextDocument(results[0].uri);
  await vscode.window.showTextDocument(document, { selection: results[0].range });
}

// Get coherence status
const status = await quantum.coherence.getStatus();
console.log(`Current coherence: ${status.coherence}`);
```
