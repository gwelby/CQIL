## Location and Usage

The documentation tools are located in `d:\CQIL\documentation\doc-tools\` and can be run individually or as a complete system:

```bash
# Run the complete documentation system
node doc-tools/quantum_documentation_system.js

# Run individual components
node doc-tools/quantum_documentation_evolver.js
node doc-tools/claude_integration_updater.js
node doc-tools/windsurf_verification_tester.js

# Set up scheduled automation
powershell -ExecutionPolicy Bypass -File doc-tools/schedule_documentation_update.ps1
```
