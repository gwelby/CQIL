## Usage

### Basic Usage

```javascript
// Import modules
const { createQuantumIndex } = require('./quantum_index');
const { enhanceQuantumIndexWithWebAccess } = require('./quantum_index_enhancement');

// Create and enhance Quantum Index
const quantumIndex = createQuantumIndex();
const enhancedIndex = enhanceQuantumIndexWithWebAccess(quantumIndex);

// Now you can access any URL without restrictions
const result = await enhancedIndex.fetchUrl("https://en.wikipedia.org/wiki/Edge_computing");
console.log(result.content);
```
